# hierarchichal-models-psychophysics
R scripts, Stan files, and data for the article: "Modeling Psychophysical Data in R: A Comparative Study of Four Model Frameworks"

The dataset simul_data.RData has been generated using the function PsySimulate() from R package MixedPsy. The The dataset vibro_exp3.RData is part of a published study (Dallmann et al., 2015) and it is also available in the MixedPsy package.
